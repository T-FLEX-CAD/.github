## Four Beats

1. **Name the model.** Give the T-FLEX CAD parametric model a short title before you set a variable.
2. **Pin the live variables.** Keep current drivers on the T-FLEX CAD board and leave unused values aside.
3. **Read the drawings.** Open T-FLEX CAD 2D 3D drawings before you move a size that already has a sheet.
4. **Check the assembly.** Read the T-FLEX CAD assembly workspace before you archive a part.
5. **Close the loop.** Clear finished variables so the next T-FLEX CAD visit does not start with a search.

## First Questions

**Does T-FLEX CAD replace every other program?**
No. T-FLEX CAD sits beside the viewer, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate T-FLEX CAD profile.

**Will T-FLEX CAD feel heavy on an older laptop?**
No. T-FLEX CAD is meant to stay readable during a normal design session.

**What should a new user try first?**
One small T-FLEX CAD variable today, then the same 2D 3D drawings tomorrow.

## Who Sits Down at T-FLEX CAD

- **Parametric desk** — sizes stay on the T-FLEX CAD parametric model.
- **Drawing set** — sheets stay with T-FLEX CAD 2D 3D drawings.
- **Assembly workspace** — mates stay on one T-FLEX CAD set.
- **Shared desk** — each T-FLEX CAD profile keeps its own pins.
- **Handoff** — the next person can read the T-FLEX CAD note without a tour.

## Field Note

T-FLEX CAD is easier to trust when the parametric model stays smaller than the folder it came from. A named part shows what is active, the variable pins show what you will change today, and the closing note tells the next person which drawing moved.

## One Real Pass

Pick a part that already has a name. Open it in T-FLEX CAD, keep only those design variables on the model, and finish one 2D or 3D drawing you can see.
